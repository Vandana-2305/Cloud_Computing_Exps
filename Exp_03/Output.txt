# EXPERIMENT 03 - GOOGLE APP ENGINE

## OUTPUT

Google App Engine was installed and configured successfully.

A new Web Application Project was created using Eclipse.

The Hello World web application was created successfully.

The application was executed successfully using the local
development server.

Local Application URL:

```
http://localhost:8888/
```

Hello World Servlet URL:

```
http://localhost:8888/helloworld
```

The application was successfully deployed to Google App Engine.

## RESULT

Thus, Google App Engine was installed successfully and a Hello World
web application was created, tested locally, and deployed
successfully in Google App Engine.
