# EXPERIMENT 08 - CREATING AND EXECUTING YOUR FIRST CONTAINER USING DOCKER

## SETUP REQUIREMENTS

1. Operating System

   * Ubuntu / Linux

2. Container Platform

   * Docker
   * Docker Engine

3. Programming Language

   * Python

4. Base Image

   * Python Docker Image

5. Terminal

   * Linux Terminal

6. Docker Hub

   * Required for accessing Docker images

## DOCKER INSTALLATION

1. Update the package repository:

   sudo apt update

2. Install Docker:

   sudo apt install docker.io

3. Verify the Docker installation:

   sudo docker run hello-world

## PROJECT SETUP

Create a project directory containing:

Docker Project/
|
+-- Dockerfile
|
+-- main.py

## PYTHON FILE SETUP

Create:

main.py

Add the Python program:

#!/usr/bin/env python3

print("Docker is magic!")

## DOCKERFILE SETUP

Create:

Dockerfile

Add the following instructions:

FROM python:latest

COPY main.py /

CMD ["python", "./main.py"]

## DOCKER IMAGE SETUP

1. Open the terminal.

2. Navigate to the project directory.

3. Build the Docker image:

   docker build -t python-test .

4. Verify the image if required:

   docker image ls

## CONTAINER SETUP

1. Run the Docker image:

   docker run python-test

2. Verify the container:

   docker ps -a

3. View container logs if required:

   docker logs [container-name]

## USEFUL COMMANDS

List Docker images:

docker image ls

Remove a Docker image:

docker image rm [image-name]

List containers:

docker ps -a

Stop a container:

docker stop [container-name]

Remove a container:

docker rm [container-name]

Display container logs:

docker logs [container-name]

## FINAL SETUP

Platform       : Docker
Base Image     : Python
Application    : Python Program
Source File    : main.py
Dockerfile     : Dockerfile
Image Name     : python-test
Execution      : docker run python-test

Expected Output:

Docker is magic!

Status         : Docker container setup completed successfully.
