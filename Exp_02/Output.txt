# EXPERIMENT 02 - VIRTUAL MACHINE – C COMPILER

## OUTPUT

The C compiler was installed successfully in the Virtual Machine.

The required libraries and GCC compiler were downloaded and
installed successfully.

The program was compiled successfully using:

```

```

```

```
